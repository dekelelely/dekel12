Each move is a list of 60 ms frames, copied from Claude Code 2.1.304. A frame names a pose (eyes, arms, feet, or a turn angle), how many rows Clawd sits below or above the floor line, and how many columns it stands off to the left. The laptop move isn't in that version; it's rebuilt from a screen recording of the Claude app, where clicking Clawd sends a ring of code across the screen while it types. The 3D version eases between frames. Unofficial fan recreation.

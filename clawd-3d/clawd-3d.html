Each move is a list of 60 ms frames, copied from Claude Code 2.1.304. A frame names a pose (eyes, arms, feet, or a turn angle), how many rows Clawd sits below or above the floor line, and how many columns it stands off to the left. Two moves aren't in that version and are rebuilt from screen recordings of the Claude app: the laptop move (clicking Clawd) and the guitar (the Ultracode effort setting). Celebrate is extended with a spin, a victory dance and confetti, since in Claude Code it matches jump. The 3D version eases between frames. Unofficial fan recreation.
